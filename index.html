Claude + Canva:
Social Media on Autopilot

A step-by-step guide to connecting Claude to Canva and generating carousels, fake-tweet posts, and any social graphic from a template — without touching a design tool.

DR
Doc Rock
youtube.com/@docrock  ·  AI Summer School

This guide walks you through exactly what Doc Rock uses to turn a single Canva template into ten (or a hundred) finished social posts in a single session — no design skills required.

Two prompts do most of the work. Everything below is the setup that makes those prompts possible.

Step 01

Connect Canva to Claude

Before Claude can touch your designs, you need to authorize the Canva connector. This is a one-time setup that takes about two minutes.

1
Open Claude.ai

Go to claude.ai in your browser. Make sure you're signed in to your account.

2
Find the Connectors menu

In the chat input area, look for the tools icon (it may appear as a grid or plug symbol). Click it to open the connectors panel.

3
Search for Canva

Type "Canva" in the search field. You'll see the official Canva connector appear in the list.

4
Click Connect and authorize

Hit Connect and follow the Canva login prompt. You're granting Claude permission to read and edit your Canva designs. Log in with the same Canva account that holds your templates.

5
Confirm the connector is active

Once authorized, you'll see a green indicator or a checkmark next to Canva in the tools panel. You're ready to go.

Good to know The connector only has access to designs in your own Canva account. It can't see designs shared with you unless they've been copied into your workspace. If you're working from a team template, make a personal copy first.
Step 02

Learn What the Connector Can Do

The Canva connector gets updated over time, and Claude only knows what tools are actually loaded in your current session. Before you start building, run this prompt to get a live inventory of every available feature — with an example of how to use each one.

Copy and paste this exactly into Claude:

Prompt 1 of 2  ·  Connector Inventory copy & paste
List all the Canva connector features available in this chat using only the current exposed tool list as a source of truth. Make a bullet point list with a sample prompt for each of the features mentioned in the Canva connector.

Claude will return a live bullet list of every Canva action it can take, like searching designs, copying templates, editing text, exporting files, and so on, with a sample prompt for each one. This tells you exactly what's possible right now so you're not guessing.

You'll typically see capabilities like:
  • Search and browse your existing Canva designs
  • Copy a design to create a duplicate (the safe way to protect your templates)
  • Open a design and read all its text elements and image slots
  • Replace text content across any page in a design
  • Rename a design and update its title
  • Export a design to PDF, PNG, or other formats
  • Merge multiple designs into a single multi-page file
One rule that matters Always work on a duplicate of your template, never the original. Claude will do this for you automatically if you ask, but make it a habit. If a transaction gets committed to the wrong file, there's no undo.
Step 03

Analyze Your Template

This is the core move. Before Claude can fill in your template, it needs to understand the structure — how many text areas there are, how large each one is, and roughly how many words fit without overflowing the design.

Share your Canva template link, then run this prompt:

Prompt 2 of 2  ·  Template Analysis + Content Fill copy & paste
[Paste your Canva template link here] Analyze this template, including the number of words per section. Ask me questions to replace the text with my own information. Roughly follow the same number of words per section.

Claude will open the template, map every editable text element, count the approximate words in each field, and then ask you targeted questions to gather your replacement content. You fill in the answers, it fills in the design.

A
Get your Canva link

In Canva, open your template and copy the share link from the top-right Share button. A short link (canva.link/xxxxxxx) or the full design URL both work.

B
Answer Claude's questions

Claude will ask about your content one field at a time — a headline here, a body sentence there. Answer in plain language. It handles the formatting.

C
Review the previews before saving

Claude shows you a thumbnail of the edited design before committing anything. Look it over. If something is off — a word count spilled, a field got scrambled — say so and it will fix it before saving.

D
Confirm and save

Once the preview looks right, tell Claude to save. It commits the changes and hands you an edit link to open the finished design directly in Canva.

Scale it

Turn One Template Into Many Posts

Running the same template ten times in a row is where this workflow gets powerful. Instead of making ten separate Canva files (which clutters your backend), ask Claude to build everything into a single multi-page design — one page per post, all in one file.

After you've run the template analysis prompt once and understand the structure, try this approach for batch runs:

Batch Prompt  ·  Multi-page build optional but recommended
[Paste your Canva template link here] Duplicate this template once. Then build [number] variations of the design, each on its own page within the same file. Here's the content for each post: — Post 1: [your content] — Post 2: [your content] — Post 3: [your content] (continue as needed) Keep the word count per section consistent with the original template. Show me a preview of each page before committing.

What You Get

📄One Canva file, multiple pages
🎨Original template untouched
👁️Preview before every save
✏️Text sized to fit each field
🔗One edit link to open it all
🗂️Clean backend, no clutter
Doc Rock's Rule Always ask Claude to duplicate the template before touching it. One command — "duplicate this first, then work on the copy" — keeps your master file safe no matter how many times you run the workflow.
If Things Go Sideways

Common Fixes

!
Claude says it can't find the design

Make sure the Canva link points to a design in your account, not one shared from someone else's. Copy it into your workspace first, then share the link.

!
Text overflows or gets cut off in the preview

Tell Claude: "That text is too long — shorten it to fit the same space as the original." It will rewrite and refit. The word count guidance from the analysis prompt helps prevent this in the first place.

!
The connector isn't responding

Try disconnecting and reconnecting Canva from the tools panel. Sometimes the authorization token needs a refresh. If that doesn't fix it, start a new Claude conversation.

!
Claude edited the original instead of the copy

This is why the duplicate step matters. If it happens, check your Canva version history — Canva keeps it under File > Version history — and restore the previous version.
